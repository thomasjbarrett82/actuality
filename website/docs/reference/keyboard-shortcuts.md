# Keyboard shortcuts

Press **?** anywhere outside a text field to see these shortcuts in Actuality, with a search box. On macOS, use **⌘** for **Ctrl** and **Option** for **Alt**; **Delete** is **Backspace**.

## General

| Action | Keys |
| --- | --- |
| Show keyboard shortcuts | **?** |
| Open a budget | **Ctrl+O** |
| Sync now | **Ctrl+S** |
| Import transactions from your bank | **Ctrl+I** |
| Export | **Ctrl+E** |
| Print | **Ctrl+P** |
| Preferences | **Ctrl+,** |
| Go to accounts | **Ctrl+T** |
| Go to budget | **Ctrl+B** |
| Go to reports | **Ctrl+R** |
| Go to Payee Settings | **Ctrl+Y** |
| Go to Rules | **Ctrl+U** |
| Privacy mode | **Ctrl+Shift+P** |
| Zoom in / out / actual size | **Ctrl+=** / **Ctrl+-** / **Ctrl+0** |
| Full screen | **F11** (macOS: **Ctrl+⌘+F**) |
| Move to the next / previous area of the window | **F6** / **Shift+F6** |
| Open the menu for the focused item | **Shift+F10** or the Menu key |
| Close a popup or menu | **Esc** |

## Budget

| Action | Keys |
| --- | --- |
| Save and move to the next / previous category | **Enter**, **Tab** or **↓** / **Shift+Tab** or **↑** |
| Discard what you typed | **Esc** |
| Quick Budget for the cell | **F2** |
| Open the calculator | **+**, **-**, **\*** or **/** while editing |
| Previous / next month (no cell selected) | **←** / **→** |
| Jump to the current month (no cell selected) | **0** |
| Scroll four rows | **Page Up** / **Page Down** |
| Collapse / expand all groups | **Ctrl+←** / **Ctrl+→** |
| Move a category or group up / down | **Alt+↑** / **Alt+↓** |

## Register

These work while the list of transactions has focus.

| Action | Keys |
| --- | --- |
| Add a transaction | **Ctrl+N** or **T** |
| Edit the selected transaction | **Enter** or **F2** |
| Edit, starting in Payee / Notes / the amount | **P** / **N** / **M** |
| Edit the date, or **Change Date…** for several | **E** |
| Search | **Ctrl+F** |
| Select all / clear the selection | **Ctrl+A** |
| Move the selection down / up | **↓** / **↑**, or **J** / **K** (add **Shift** to extend) |
| Mark cleared / uncleared | **L** or **Ctrl+Shift+C** |
| Approve | **V** |
| Categorize As | **C** |
| Move to account | **A** |
| Make recurring | **S** |
| Match | **G** |
| Delete | **Delete** or **D** |
| Undo a delete (while the Undo message shows) | **Ctrl+Z** |
| Sort again | **F5** |
| Add a sort level (on a column header) | **Shift+click** or **Shift+Enter** |

## Editing a transaction

| Action | Keys |
| --- | --- |
| Next / previous field | **Tab** / **Shift+Tab** |
| Save (the default button) | **Enter** |
| Save and close, from any field | **Ctrl+Enter** |
| Save a new transaction and make it recurring | **Ctrl+Shift+Enter** |
| Save, then edit the transaction above | **Shift+Enter** |
| Toggle cleared | **Ctrl+Shift+C** |
| Undo the change to this field / cancel the edit | **Esc** / **Esc** again |
| Open the calculator (in Outflow or Inflow) | **+**, **-**, **\*** or **/** |
| Next check number (in Check #) | **Alt+N** or **Ctrl+Shift+N** |
| Check number up / down (in Check #) | **↑** or **+** / **↓** |

### In a date field

| Date | Keys |
| --- | --- |
| Next / previous day | **+** or **↑** / **-** or **↓** |
| Today | **T** |
| First / last day of the month | **M** / **Shift+M** |
| First / last day of the year | **Y** / **Shift+Y** |
